# cyberpunk2077-assets

Тайлы подложки для интерактивной карты [Cyberpunk 2077](https://broskiplay.ru/cyberpunk2077-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/night-city/<z>/<x>/<y>.avif` (512×512, z0–z6) и `tiles/night-city/manifest.json` — список существующих тайлов
- Карта: `night-city` (Найт-Сити, Пёсий город и Пустоши)

Тайлы взяты с [etalongame.com](https://etalongame.com/interactive-maps/cyberpunk-2077/map/night-city/) как есть (без перекодирования).
